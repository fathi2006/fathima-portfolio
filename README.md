# Fathima Mary V — Python Developer Portfolio

A responsive, dark premium portfolio built with React, Vite, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally

1. Extract this ZIP.
2. Open the extracted `fathima-python-portfolio` folder in VS Code.
3. Open the terminal in that folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.
